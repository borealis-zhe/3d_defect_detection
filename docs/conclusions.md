# 实验结论

更新时间：2026-10-30（北京时间）。本文件只记录事实，不保留旧启动计划。

## 当前主线

训练使用12类、48个正常点云，冻结DINOv2，重训MLP瓶颈和8层解码器；每类5000步、batch 16、seed 1。B/C都从初始化训练，不互相续训。

测试使用 `exterior_camera_all_v1` 的603个对象，包含167个方向/匹配不确定的候选；15测试视图，参考点来自主相机112网格，逐视图分数直接平均，物体分数取最大点分数。未加入可见性加权、平滑或辅助任务。

| 训练方案 | 物体AUROC % | 点AUROC % | Point AP % |
|---|---:|---:|---:|
| 原单侧训练，同一新测试相机 | 85.00 | 94.95 | 46.47 |
| B 双侧26图 | 93.37 | 97.96 | 63.47 |
| C 全方位26图 | 94.23 | 98.27 | 64.46 |

C相对B增加0.86／0.31／0.99个百分点，仍为单种子探索性结果。

B由两个13方向的球冠构成，每侧中心1个、15°环4个、30°环8个。C使用6个面、12个边、8个顶点方向。B相机距离2.5；C的1248张图中15张为防裁切后移相机，最大距离2.7185466。因此现有B/C比较并非完全单变量。

## 证据位置

- 本地B配对结果：`outputs/bilateral26_eval/paired_training_comparison.json`、同目录`评估报告.md`。原训练与B的603组原始参考点编号及标签已核验一致。

- C汇总：`macro_metrics.json`；逐类结果：`eval/<category>/metrics.json`；训练报告：`train/<category>/training_report.json`。
- C完成状态已通过服务器日志与退出码核验；C/B预测点域及模型哈希的本地逐样本复核尚未完成。

## 仍须保留的局限

参考点域不是全部扫描表面。167个不确定相机被纳入不等于位姿问题已解决。测试集已多次参与探索；不把现有结果视为独立盲测或官方论文指标复现。以前同伴报告中的80.06／88.91／44.44采用另一测试几何设置，不能与B/C直接相减来归因训练收益。

同伴的辅助预测头与后处理结果属于另一实验链；本项目早期选点、选视图与几何消融也基于旧模型/点域，均不能充当B/C主线上的已完成消融。


## 早期实验的有效结论

以下结论来自旧权重和旧评估几何，不与当前B/C作直接数值排名。

- 交接包基线经保存预测复算为80.0634／88.9076／44.4354；重新计算15视图均值与603对象保存预测最大误差约2.09×10⁻⁷。这是核验已有模型，不是本地重训。
- 旧基线上可见均值、中位数共识、视角分歧项均未提高预定主指标Point AP。覆盖率贪心也未证明定位提升，覆盖率大不等于分数正确。
- 直接按原顺序删到3/5/9视图不是公平的选视角对照；前三张含近似同方向的画面内旋转。均匀5视图仅有探索性的效率线索，没有稳定超过基线的证据。
- 前表面选点会漏掉缺陷：旧飞机635_sink共有4825原始异常点，旧112网格参考域仅保留2个；扩大至可评价可见原始点可保留4193个。但旧模型全部可见点Point AP仍约43.79%，扩大点域不会自动修复模型。
- 姿态配准和外侧相机估计解决几何对应问题，但对称性、局部壳体和法线歧义仍可能造成错向。没有真实相机标定，不能把虚拟相机当成恢复出的扫描仪位姿。
- AUROC升而AP降并不矛盾：整体正常/异常排序可能改善，但高分区域的正常点误报仍会降低精确率；这在异常点稀少时尤为明显。

主线目前证实的是B/C训练视角方案的结果差异。去对侧、缩小倾角、多种子和评分模块等新消融尚未执行，不能写为已验证贡献。
